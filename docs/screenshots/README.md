# Screenshots wanted

Drop PNGs in this folder using the exact filenames below, then open the main
[README.md](../../README.md), find the matching `> **Screenshot wanted**` blockquote and
replace it with the commented-out `![...]` line sitting directly underneath it.

Capture at a **normal window size** (not fullscreen on a 4K panel) so text stays legible
once GitHub scales the image down. PNG, not JPG — the UI is flat colour and text.

| `chest-strain.png` | An Ornate chest mid-strain, just before the lid gives. |
